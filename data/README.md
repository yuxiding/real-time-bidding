# Data provenance

All supported experiment data is generated by `aurorabid.data.generate_data`.
There are no real users, customer records, or external datasets in this version.
Generation is deterministic given the row count and data seed.

| Table | Observable | Simulator-only / unavailable |
|---|---|---|
| Opportunities | Request ID, user ID, timestamp, age, segment, slot, reserve price | Competing price and potential click/conversion outcomes |
| Background activity | Historical events after their own timestamps | Events that have not occurred yet |

Activity is independent of the evaluated policy. Current auction labels never
enter features. Data and activity hashes are recorded in `reports/run_metadata.json`.
Generated raw tables do not need to be committed.
